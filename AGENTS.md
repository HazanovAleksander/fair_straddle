# AGENTS.md

Правила и контекст проекта для ИИ-агентов.

## Обзор проекта

Однофайловый терминальный бот `fair_straddle.py`: покупка ATM-стредда (call + put)
на опционах Bybit через `pybit`. Лимитная цена каждого плеча — `min(марка, аск − тик)`
без пересечения спреда (`limit_price`), атомарная выставка обоих плеч или отмена
(`do_place`). Dry-run по умолчанию; `--live` включает реальные ордера.

Ключевые структуры:

- `Leg` — инструмент (symbol, страйк, тик, лимиты количества)
- `Series` — серия экспирации, страйки с полными парами C/P
- `State` — общее состояние под `RLock`: тикеры, индекс, ордера, сообщения
- `Cfg` — конфигурация запуска (base, qty, live, testnet, strikes)
- `Term` / `render` — терминальный UI (cbreak-режим, перерисовка 4 Гц)

Данные: REST-снапшот (`seed_tickers`) + публичный WS tickers (подписка до 380
символов вокруг индекса, `pick_subscription_symbols`); статусы ордеров — приватный
WS `order_stream` (только в live).

## Команды

```bash
# установка
pip install -r requirements.txt

# запуск (dry-run, безопасно)
python fair_straddle.py BTC 0.01
```

Тестов и линтеров в проекте нет. Проверять изменения — запуском dry-run.

## Соглашения по коду

- Python 3.10+; только stdlib + `pybit` (см. requirements.txt)
- Все цены и количества — `Decimal` (не float); строковое представление для API
- Без комментариев в коде
- Тексты UI и сообщений — на русском
- Стиль: dataclass для неизменяемых данных, блокировки `state.lock` при доступе
  к общему состоянию из потоков WS
- Совместимость с терминалом: цвет/ширина колонок определяются по `isatty` и
  `shutil.get_terminal_size`

## Безопасность

- **Запрещено запускать `--live` без явного разрешения пользователя** — это
  реальные ордера на бирже. Для проверки всегда использовать dry-run или
  `--testnet`
- API-ключи вводятся интерактивно; не сохранять их в файлах, переменных
  окружения в репозитории, логах или коде
- Изменения логики выставки/отмены ордеров (`do_place`, `do_cancel_own`,
  `limit_price`) — только по явной просьбе пользователя
