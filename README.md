# Fair Straddle

Терминальный бот для покупки ATM-стредда (call + put на одном страйке) на опционах ByBit.
Работает с ближайшими сериями (0DTE / 1DTE), выставляет лимитные заявки по цене
`min(марка, аск − тик)` — не пересекая спред. По умолчанию работает в режиме
**dry-run** (ордера не отправляются).

## Возможности

- Выбор конструкции клавишами ↑/↓: стреддл (ATM call + put) или стренгл ±1 / ±2 / ±3
- Лимитная цена каждого плеча: `min(марка, аск − тик)` с округлением вниз до тика и минимумом `minPrice`; если цену без пересечения аска выставить нельзя — выставка отменяется
- Атомарная выставка: оба плеча (call и put) или ничего
- Пробел: одиночное нажатие — лимитные заявки; двойное (≤300 мс) — рыночные ордера сразу, без выставления лимитных; после выставки лимитных — отмена активных лимитов и выкуп неисполненного остатка рыночными
- Сводка по каждой конструкции: стоимость покупки рыночным ордером (Σ асков), максимальная стоимость при покупке лимитными ордерами (Σ (аск − тик)), уровни Short/Long фьючерса относительно лимитной покупки (`K ± 1.2 × лимитная стоимость`), максимальный убыток на экспирации
- Live-таблица страйков: бид/аск (с размерами при ширине терминала), марка, IV, расчётный лимит
- Отслеживание статусов ордеров через приватный WebSocket
- Telegram-уведомления в live-режиме: выставка/отмена ордеров, исполнения, итоговая стоимость собранной конструкции с комиссиями
- Режимы: dry-run (по умолчанию) / `--live`, mainnet / `--testnet`

## Установка

Требуется Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Использование

```bash
python fair_straddle.py <base> <qty> [--testnet] [--strikes N] [--live]
```

- `base` — `BTC` или `ETH`
- `qty` — количество в монетах: для BTC кратно `0.01`, для ETH кратно `0.1`
- `--strikes` — полуокно страйков в таблице (по умолчанию 3)
- `--testnet` — тестовая сеть
- `--live` — реальная отправка ордеров (по умолчанию dry-run)

Примеры:

```bash
# dry-run, mainnet
python fair_straddle.py BTC 0.01

# dry-run, testnet, окно в 5 страйков
python fair_straddle.py ETH 0.5 --testnet --strikes 5

# реальная торговля (запросит API key/secret)
python fair_straddle.py BTC 0.05 --live
```

При запуске с `--live` запрашиваются ключи API Bybit (аккаунт Unified,
право **Trade**). Ключи вводятся интерактивно и нигде не сохраняются.

## Выбор серии

Если доступно несколько серий, бот предложит выбрать:

1. **0day** — ближайшая к экспирации
2. **1day** — следующая за ней

По умолчанию (Enter) выбирается ближайшая, если до её экспирации больше 4 часов,
иначе — следующая.

## Управление

| Клавиша | Действие |
|---|---|
| `↑` / `↓` | Выбор конструкции (Стреддл / Стренгл ±1 / ±2 / ±3) до выставки |
| `ПРОБЕЛ` | Выставить лимитные заявки по выбранной конструкции; двойное нажатие (≤300 мс) — рыночные ордера сразу |
| `ПРОБЕЛ` (после выставки) | Отменить активные лимитные ордера и выкупить неисполненный остаток рыночными |
| `ESC` | Отменить все активные ордера, выставленные ботом |
| `q` / `Ctrl+C` | Выход |

## Требования к количеству

Помимо кратности (BTC — 0.01, ETH — 0.1), количество проверяется по лимитам
выбранной серии (`minOrderQty`, `maxOrderQty`, `qtyStep`) при запуске.

## Telegram-уведомления

Работают только в `--live`. Токен бота и ID канала берутся из переменных
окружения или файла `.env` рядом со скриптом (см. `.env.example`):

```
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHANNEL_ID=@channel_or_chat_id
```

Бот должен быть администратором канала с правом отправки сообщений.

Отправляемые события:

- выставка лимитных или рыночных ордеров (одно сообщение на конструкцию)
- отмена ордеров (по ESC или при конвертации лимитов в рынок)
- исполнение или отмена ордера (по событиям приватного WebSocket)
- конструкция собрана: премия по плечам, комиссии и итог с комиссиями

Без заданных переменных бот работает как раньше, без уведомлений.

## Риски

`--live` отправляет реальные ордера на биржу и может привести к потере средств.
Максимальный убыток конструкции (полная потеря премии на экспирации) отображается
в интерфейсе. Рыночные ордера (двойной пробел или конвертация лимитных) исполняются
немедленно по текущим ценам стакана и дают проскальзывание. Используйте `--testnet`
и dry-run для проверки.
